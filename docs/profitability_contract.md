# Profitability Contract

**Status: Provisional — pending real anonymized data and invoice reconciliation**

Profitability will be deterministic and auditable in SQL/Python. The ideal direction is revenue less reliable observed product cost, non-duplicated discounts, delivery/freight, handling, and return loss. Missing costs will not be invented.

The final metric name and formula remain unfrozen. If outbound delivery/handling is absent, a candidate honest name is **Observed Contribution Profit Before Outbound Delivery**. Freeze v1 only after reconciling 20–30 invoices with the source accounting report and documenting tax, discount, return, and cost-timing differences.
